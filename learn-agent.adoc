= NetApp Workload Factory의 AI 에이전트에 대해 알아보세요.
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Workload Factory AIOps는 AI를 사용하여 환경을 분석하고 개선 사항을 권장합니다. 사용자가 승인하면 설정한 자격 증명과 권한을 사용하여 필요한 조치를 취할 수도 있습니다.


NOTE: 계정 관리자가 AI 기능을 비활성화한 경우 메시지가 표시되고 상담원을 사용할 수 없습니다. 관리자에게 문의하거나 link:manage-genai-features.html["AI 관리에 대해 알아보기"].



[[before-you-begin]]
== 시작하기 전에

Workload Factory 계정에 AWS 자격 증명과 에이전트가 액세스하는 리소스에 필요한 IAM 권한이 있는지 확인하십시오. 읽기/쓰기 모드를 활성화하는 경우 해당 권한에는 지원되는 변경 사항도 허용되어야 합니다.

link:add-credentials.html["AWS 자격 증명을 추가하고 IAM 권한을 설정하는 방법을 알아보십시오."^].



[[data-usage-and-privacy]]
== 데이터 사용 및 개인정보 보호

사용자 데이터는 AI 모델 학습에 사용되지 않습니다. 에이전트는 사용자 자격 증명을 사용하여 표준 AWS API를 통해 AWS 리소스에 안전하게 액세스하고 실제 환경에 따라 응답합니다. 모든 에이전트 활동은 NetApp 개인정보 보호 정책 및 AWS 보안 제어를 준수합니다.



[[why-use-ai-agents]]
== AI 에이전트를 사용하는 이유

AI 에이전트는 Workload Factory에서 더욱 효율적으로 작업할 수 있도록 도와줍니다.

* 사용자의 환경에 맞는 답변과 권장 사항을 받아보세요.
* 위험 요소와 최적화 기회를 파악합니다.
* 문제를 해결하고 승인된 조치를 하나의 워크플로에서 수행합니다.
* 예약된 점검을 실행하고 채팅 기록에서 업데이트를 받으세요.
* FSx for ONTAP 및 Google Cloud NetApp Volumes 환경에서 작업합니다.




[[access-the-ai-agents]]
== AI 에이전트에 액세스합니다

Ask Me 홈 페이지에서:: Ask Me 랜딩 페이지에서 *에이전트 살펴보기*를 선택합니다. AI 에이전트 사이드 패널이 열리고 에이전트의 기능을 소개하는 환영 메시지가 표시됩니다.
에이전트 리디렉션 링크에서:: **Ask Me** 또는 다른 기능을 사용할 때, 더 자세한 도움을 받기 위해 상담원에게 연결되는 링크가 표시될 수 있습니다.

[[how-agents-access-your-environment]]
=== 에이전트가 환경에 액세스하는 방법

에이전트는 현재 Workload Factory 범위에 포함되어 있고 link:manage-agent-settings.html["에이전트 설정"]에서 선택된 자격 증명으로 지원되는 리소스에만 액세스할 수 있습니다. 에이전트는 두 가지 제어 조건이 모두 적용되는 경우에만 작동할 수 있습니다. 에이전트가 액세스할 수 있는 리소스는 AWS 자격 증명에 할당된 권한에 따라 달라집니다. 기본적으로 모든 자격 증명이 선택되어 있지만, 구성된 자격 증명의 하위 집합으로 줄일 수 있습니다.

현재 담당 업무 범위는 다음과 같습니다.

* *AWS 계정*: 에이전트가 액세스할 수 있는 AWS 계정입니다.
* *자격 증명*: 에이전트가 사용할 수 있는 자격 증명입니다.
* *리전*: 에이전트가 액세스할 수 있는 AWS 리전입니다.


Workload Factory의 필터는 현재 보고 있는 AWS 계정 및 리전 등 현재 페이지의 범위를 설정합니다. 에이전트 설정은 해당 범위 내에서 에이전트가 사용할 수 있는 자격 증명을 제어합니다. 리소스에 대한 액세스는 해당 자격 증명에 할당된 IAM 권한에도 따라 달라집니다.


NOTE: *Agents settings* 에서 자격 증명을 선택한다고 해서 AWS 권한이 추가로 부여되는 것은 아닙니다. 에이전트가 분석 또는 관리하려는 리소스에 액세스하려면 자격 증명에 필요한 IAM 권한이 있는지 확인하십시오.



[[read-only-mode-default]]
=== 읽기 전용 모드(기본값)

기본적으로 에이전트는 읽기 전용 모드로 작동합니다. 이 모드에서 에이전트는 다음과 같은 작업을 수행할 수 있습니다.

* 환경에 대한 질문에 답하십시오.
* FSx for ONTAP 파일 시스템, 데이터베이스 및 워크로드를 분석하십시오.
* 위험 요소, 잘못된 구성 및 최적화 기회를 파악합니다.
* 성능, 가용성, 보호 및 비용 효율성을 개선하기 위한 권장 사항을 제공합니다.
* 문제점을 파악하고 해결 방안을 제시합니다.


읽기 전용 모드에서는 리소스를 변경할 수 없습니다. 쓰기 권한이 필요한 작업을 요청하면 에이전트가 제한 사항을 설명하고 에이전트 설정 링크를 제공합니다.



[[read-write-mode-opt-in]]
=== 읽기/쓰기 모드(옵트인)

읽기/쓰기 기능을 link:manage-agent-settings.html["에이전트 설정"]에서 활성화할 수 있습니다. 이 모드에서는 에이전트가 지원되는 각 작업에 대해 설명하고 변경 사항을 적용하기 전에 사용자의 승인을 요청합니다.

이 승인 절차는 Slack 통합 및 NetApp Console을 포함한 모든 에이전트 환경에 적용됩니다.



[[what-users-see-when-ai-agents-have-no-data-or-activity]]
== AI 에이전트에 데이터나 활동이 없을 때 사용자가 보는 화면

자격 증명이 없는 에이전트라도 일반적인 안내는 제공할 수 있습니다. 하지만 사용자의 리소스를 검토하거나 특정 환경에 맞는 맞춤형 분석 정보를 제공할 수는 없습니다.
