= 운영 상황을 추적하고 모니터링합니다
:allow-uri-read: 


FSx for ONTAP, 자격 증명 및 링크 작업의 실행을 모니터링하고 추적하며 NetApp Workload Factory의 Tracker를 사용하여 작업 진행 상황을 모니터링합니다.

.이 작업에 대해
Workload Factory는 모니터링 기능인 Tracker를 제공하여 FSx for ONTAP, 자격 증명 및 링크 작업의 진행 상황과 상태를 모니터링하고 추적하고, 작업 및 하위 작업에 대한 세부 정보를 검토하고, 문제 또는 오류를 진단할 수 있도록 지원합니다.

트래커에서는 다양한 작업을 수행할 수 있습니다. 기간(최근 24시간, 7일, 14일 또는 30일), 작업량, 상태 및 사용자별로 작업을 필터링할 수 있고, 검색 기능을 사용하여 작업을 찾을 수 있으며, 작업 테이블을 CSV 파일로 다운로드할 수 있습니다. 트래커는 언제든지 새로 고침할 수 있습니다. 실패한 작업을 빠르게 재시도하거나 실패한 작업의 매개변수를 수정하여 다시 시도할 수도 있습니다.

트래커는 작업 유형에 따라 두 가지 수준의 모니터링을 지원합니다. 파일 시스템 배포 등 각 작업에 대해 작업 설명, 상태, 시작 시간, 작업 기간, 사용자, 지역, 프록시 리소스, 작업 ID 및 모든 관련 하위 작업이 표시됩니다. API 응답을 확인하여 작업 중에 발생한 상황을 파악할 수 있습니다.

추적 작업 레벨 예시::
+
--
* 레벨 1(작업): 파일 시스템 배포를 추적합니다.
* 레벨 2(하위 작업): 파일 시스템 배포와 관련된 하위 작업을 추적합니다.


--
운영 상태:: 트래커에서 작업 상태는 _진행 중_, _성공_, _실패_로 표시됩니다.
+
--
작동 주파수:: 작업 빈도는 작업 유형과 작업 일정에 따라 결정됩니다.


--
이벤트 보존:: 이벤트는 사용자 인터페이스에서 30일 동안 보관됩니다.




[[track-and-monitor-operations]]
== 운영 상황을 추적하고 모니터링합니다

Tracker를 사용하여 NetApp Console에서 작업을 추적하고 모니터링합니다.

.단계
. 다음 중 하나를 사용하여 로그인하세요link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["콘솔 환경"^].
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 스토리지, EDA, AI, 데이터베이스, VMware 및 관리와 같은 워크로드를 탐색하는 데 사용됩니다."]를 선택한 다음 *관리*를 선택하십시오.
. 관리 메뉴에서 *Tracker*를 선택합니다.
. 트래커에서는 필터 또는 검색 기능을 사용하여 작업 결과를 좁힐 수 있습니다. 작업 보고서를 다운로드할 수도 있습니다.




[[view-api-request]]
== API 요청 보기

트래커의 작업에 대한 API 요청을 Codebox에서 확인하십시오.

.단계
. 트래커에서 작업을 선택합니다.
. 작업 메뉴를 선택한 다음 *API 요청 보기*를 선택합니다.




[[retry-a-failed-operation]]
== 실패한 작업 재시도

트래커에서 실패한 작업을 다시 시도할 수 있습니다. 실패한 작업의 오류 메시지를 복사할 수도 있습니다.


NOTE: 실패한 작업에 대해 허용되는 재시도 횟수는 x회로 제한됩니다.

.단계
. 트래커에서 실패한 작업을 선택합니다.
. 작업 메뉴를 선택한 다음 *다시 시도*를 선택합니다.


.결과
작업이 다시 시작되었습니다.



[[edit-and-retry-a-failed-operation]]
== 실패한 작업 편집 및 재시도

실패한 작업의 매개변수를 수정하고 Tracker 외부에서 작업을 다시 시도하십시오.

.단계
. 트래커에서 실패한 작업을 선택합니다.
. 작업 메뉴를 선택한 다음 *편집 후 다시 시도*를 선택합니다.
+
매개변수를 수정하고 작업을 다시 시도할 수 있는 작업 페이지로 이동합니다.



.결과
작업이 재시작되었습니다. Tracker에서 작업 상태를 확인하십시오.
